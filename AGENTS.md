# Project Rules

- Row-style button plaques must align like the main list menu: use `--row-menu-inset-left` and `--row-menu-inset-right` instead of hard-coded local offsets.
- Row-style action buttons on secondary screens must reuse the main menu plaque treatment (`/src/assets/button.png`, `background-size: 100% 122%`, 50px icon column, 48px row height) unless a screen-specific canon says otherwise.
- Green title badges must match the battle deck title badge: use `/src/assets/bage/green.png`, `height: 64px`, `background-size: 100% 100%`, and the deck title typography treatment.
- Secondary screens inside `GameScreen` must not define their own full-screen background image or page-wide tint. Use transparent screen backgrounds so the shared `--game-bg-image` remains consistent across screens.
- All screens and their primary content blocks must stay centered within the shared `GameScreen` frame. Use the existing shared insets, constrained widths, auto margins, centered grids/flex layouts, and `justify-content: center` patterns instead of screen-specific left/right offsets.
- Text colors must follow the dark fantasy palette: titles use old gold `--text-title-gold`, body/caption text uses parchment `--text-main-parchment`, muted labels use `--text-muted-gold`, and links/help/accent text may use only subdued jade `--text-help-jade`. Do not use bright cyan/blue for ordinary UI text or notice panels; reserve blue only for element-specific art, rarity/element coding, icons, or non-text effects where canon requires it.
- Card and battle-deck behavior must follow `docs/deck-canon.md` first, then `docs/card-rules.md` only for older auxiliary reference. Do not invent card stats, rarity ranges, deck rules, HP rules, collection bonuses, source-card behavior, or upgrade costs outside those references.
- Framed cards must render through the shared `CardSlot` component and `CardSlot.css` geometry on every framed-card screen. Do not override the internal power number, artwork crop, frame, or element badge placement per screen. Collections are the exception because collection cards intentionally do not use the frame.
- Card power numbers must be text-only overlays placed in the frame's built-in power slot. Do not add a separate power icon inside framed cards; the frame art already contains the icon area.
- Framed-card geometry is based on a 1024x1536 frame. Power is only in x 310-850 / y 105-210. Element badge is only in x 747-937 / y 1158-1348. Card name, when shown, is only in x 190-750 / y 1245-1315.
- Typography must use the project font variables: `--font-title` (`Cinzel`) for tabs, buttons, card names, headings, and card/currency/HP numbers; `--font-decor` (`Cinzel Decorative`) only for large decorative titles; `--font-body` (`EB Garamond`) for descriptions, hints, menu text, card info, dialogs, captions, and long explanations. Do not use `Cinzel Decorative` for small text.
